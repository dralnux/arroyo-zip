# Personal OS — Retro Terminal Website

A from-scratch, GitHub Pages-ready retro terminal portfolio inspired by vintage computer interfaces.

## Run locally

Open `index.html` in a browser.

## Customize

Edit:

- `index.html` — page structure and navigation
- `css/style.css` — colors, CRT effects, layout
- `js/app.js` — terminal commands and links

Replace the placeholder GitHub, LinkedIn, email, biography and resume information before publishing.

## GitHub Pages

Upload the contents of this folder to a GitHub repository and enable GitHub Pages from the repository settings. Because this is a static HTML/CSS/JavaScript site, no server is required.
